# DippingBook

## 실행 방법

PyCharm에서 프로젝트 폴더를 연 뒤 아래 순서대로 실행합니다.

```powershell
python -m pip install -r requirements.txt
python app.py
```

실행 후 브라우저에서 아래 주소로 접속합니다.

```text
http://127.0.0.1:3000
```

## 참고

- Python이 설치되어 있어야 합니다.
- 처음 실행할 때만 `requirements.txt` 설치가 필요합니다.
- 종료할 때는 터미널에서 `Ctrl + C`를 누릅니다.
